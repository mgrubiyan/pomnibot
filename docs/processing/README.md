# Обработка учебных материалов

Backend сохраняет текстовый слой, чтение изображений, блоки и таблицы отдельно от
визуальных интерпретаций. Генератор строит тематический план по исходным блокам,
создаёт карточки и проверяет их отдельным модельным запросом. Принятые пакеты выдаются
постепенно; непокрытые цели остаются в отчёте. Совпадение цитаты с источником само по
себе не доказывает правильность ответа.

## Ограничения и хранение

- Общий бюджет документа учитывает чтение, генерацию, проверку, транспортные повторы
  и параллельные резервы. Потерянный ответ сохраняет полный денежный резерв.
  Для OpenRouter по умолчанию: 96 попыток и $0,15; несовместимый или непрайсированный
  fallback не обходит явно заданный денежный предел.
- При тайм-ауте вызова PLAN/REVIEW возможен один повтор с новым контекстом, в пределах
  общего бюджета и дедлайна документа. Отмена документа и исчерпание бюджета не
  повторяются. Сетевые ошибки журналируются через slog без секретов и текста материала.
- Кеш чтения учитывает пользователя, исходные файлы, модель, настройки, версию,
  инструкцию и схему. `ReadFailed` и запасной текст после сбоя не считаются успешным
  visual-чтением. Кеш приложения ограничен 64 МиБ и одним часом; CLI поддерживает
  отдельный приватный файл чтения между запусками.
- Миграция `00009_processing_reports.sql` добавляет приватный отчёт с оригиналами,
  чтением, основаниями, вердиктами и покрытием. Доступ — только автору набора;
  удаление набора каскадно удаляет отчёт. Публичный OpenAPI не меняется.
- Интерпретации изображений не становятся дословными цитатами. Обрезанные условия
  нельзя восстанавливать внешними знаниями. Сложные пространственные связи PPTX
  без полного рендера требуют PDF; автоматическая проверка модели остаётся ошибочной.

## Локальная проверка

Из корня репозитория:

```sh
task lint
POMNIBOT_LIVE_CORPUS=0 POMNIBOT_LIVE_REPLAY=0 POMNIBOT_LIVE_BUDGETED=0 \
POMNIBOT_LIVE_SQL_SUBSET=0 POMNIBOT_LIVE_SQL_SUBSET_CONTINUE=0 \
GOFLAGS=-count=1 task test

task cardsgen -- -extract -ocr local -json /path/to/lecture.pdf
```

Локальное извлечение не доказывает успешное чтение изображений. Платные `TestLive*`
отключены по умолчанию и требуют явного opt-in. Ключи берутся из локального окружения;
их нельзя включать в вывод или артефакты.

Для отдельно согласованного платного запуска CLI предоставляет `-budget-usd`,
`-max-calls`, `-call-timeout`, `-concurrency`, `-coverage-repairs` и `-reading-cache`.
Сначала нужно оценить весь процесс, включая изображения, максимальный выход,
повторы и потерянные ответы. Финальный stdout CLI не гарантирует сохранение карточек
при аварии. Проверочный сценарий `backend/cmd/cardsgen/subset_eval_test.go` сохраняет
запросы, ответы, изображения и принятые пакеты постепенно в игнорируемой `.task/processing`.
Сам сценарий фиксирует конкретный SQL-образец; номера его страниц не входят в алгоритм.

## Фактически проверенный результат

Последний реальный тест использовал оригинальные страницы 28–29 SQL-PDF: шаблоны,
запросы и таблицы UPDATE/DELETE до и после. Обе страницы успешно прочитаны через
OpenRouter и независимо сверены с оригинальными изображениями. PLAN не вернул ответ
за 80 секунд; генерация не началась. Получено и принято **0 карточек**. Качество
карточек, дистракторов, смысловые повторы и пригодные задачи на применение не измерены.

Известная цена двух чтений — $0,0023917; тайм-аут учтён полным резервом $0,0050726.
Консервативно списано $0,0074643; из прежнего общего бюджета $0,20 остаётся $0,0591144.
Чтение заняло 21,698 с, неуспешная попытка целиком — 101,938 с. Время генерации,
проверки, первой проверенной карточки и цена пригодной карточки неизвестны.
Эти длительности нельзя сравнивать с полным baseline как равнозначный прогон.

Полный SQL-прогон не запускался: только консервативная выходная часть чтения
36 страниц при 8000 токенах составляет $0,144 и превышает остаток бюджета.
Карта [sql-map.json](sql-map.json) сохраняет 19 тем и знаменатель **61 цель**;
индивидуальные тексты и ID целей недоступны, поштучное сопоставление невозможно.
Нового подтверждённого покрытия нет.

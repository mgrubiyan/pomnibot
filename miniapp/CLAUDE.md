# Помнибот — мини-приложение

Фронтенд мини-приложения для мессенджера MAX. Бэкенд делают другие
участники команды, он лежит в ../backend — туда не лезем.

Продуктовый контекст: ../docs/concept.md
Макеты экранов: ./design/screens.html — референс композиции.
Структуру и иерархию берём оттуда, но реализуем на компонентах
@maxhub/max-ui и переменных дизайн-системы. Инлайновые стили
из макета не переносим.

## Стек
React 18 + TypeScript + Vite, библиотека @maxhub/max-ui.
Состояние — useState и контекст, без Redux. Запросы через fetch.

## Правила
- Все цвета только через CSS-переменные MAX UI: --background-card,
  --background-surface, --text-primary, --text-secondary,
  --text-tertiary, --button-primary, --icon-positive, --icon-negative,
  --divider-primary. Хардкодить хексы нельзя — сломается тёмная тема.
- Компоненты берём готовые из @maxhub/max-ui: Button, IconButton,
  Panel, Container, Flex, Grid, Input, Textarea, Spinner, Typography,
  Cell*. Вручную верстаем только ленту карточек и экран итогов.
- Высота через 100dvh, не 100vh.
- Отступы кратны 4: 4, 8, 12, 16, 20, 24. Поля экрана 16px.
- Скругление карточки 16px, кнопок 12–16px.
- Обязательны состояния: загрузка, ошибка с повтором, пустой список.
- Работать должно и в мобильной, и в веб-версии MAX.

## Данные
Пока верстаем на моках: src/mocks.ts, типы в src/types.ts.
Реальный API подключим позже — не придумывай эндпоинты сам,
спрашивай.

## Экраны
- Home — «на сегодня», список наборов, кнопки добавления.
- Feed — лента карточек: вопрос, ответ, объяснение, цитата-источник.
- Result — итоги прохождения, темы с ошибками, шеринг набора.

## Чего не делать
- Рейтинги, лайки, стрики, соревнование между студентами.
- localStorage и sessionStorage.
- Свои цвета вне дизайн-системы, градиенты, тени-подсветки.
- Тяжёлые библиотеки под анимацию: свайп делаем на CSS transform.

## Команды
- npm run dev — дев-сервер
- npm run build — сборка
- npm run lint — проверка

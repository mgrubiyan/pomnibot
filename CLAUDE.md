# Pomnibot — Guidelines for Claude

See [AGENTS.md](AGENTS.md) for full project rules, coding standards, and commit message conventions.

## Commit Guidelines
- Commit messages **must** follow [Conventional Commits](AGENTS.md#commit-messages) in English (e.g., `feat: ...`, `fix: ...`).
- Do not use Russian in commit messages.
- Do not add assistant co-author trailers.

## Commands
- `task dev` — run frontend development server
- `task build` — build frontend
- `task lint` — run all linters (`miniapp` and `backend`)
- `task test` — run backend unit tests

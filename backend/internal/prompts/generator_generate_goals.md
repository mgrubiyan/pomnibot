Формат ответа:
- Используй GFM + math в question, строковых answer, source (объяснениях), вариантах выбора и элементах сортировки: разрешены Markdown-таблицы, списки, выделение и код. Формулы — LaTeX с $...$ внутри текста и $$...$$ отдельным блоком; обратные слеши экранируй по правилам JSON. Не возвращай HTML или SVG. name факта — обычный текст; sourceQuote — неизменная дословная цитата. Тип table остаётся интерактивным заданием на сортировку по 2–4 категориям: Markdown-таблица служит только оформлением входных данных.
- Верни непустой массив facts. Каждый факт содержит name, pages, recall и extraCards. pages — страницы факта, нумеруемые с 1 сквозным порядком файлов.
- recall обязателен и содержит question на воспроизведение или применение, непустые строковые answer и source, строковый sourceQuote (может быть пустым); kind отсутствует. Сервер автоматически создаёт пару flip/input с побайтово одинаковыми question, answer, source и sourceQuote. Отдельные flip и input запрещены.
- extraCards обязателен, может быть []. Разрешены kind: recall, boolean, choice, table. Строго соблюдай схему каждого типа:
  * boolean: логический answer (true или false); вопрос проверяет истинность правила, граничный случай или заблуждение. Запрещено упаковывать булевы проверки («верно ли», «да/нет», «true/false») в карточку recall со строковыми ответами «Ложно: ...», «Истина: ...» или «true».
  * table: columns с 2–4 категориями name и непустыми rows понятий/примеров (по 2–4 на категорию; если в материале есть классификация, деление понятий на группы, виды или режимы либо противопоставление классов объектов). Запрещено выдавать классификацию или распределение элементов в виде Markdown-таблицы внутри answer карточки recall — для этого используется исключительно интерактивная схема table. Markdown-таблицы в question разрешены и приветствуются для подачи исходных табличных данных задачи, но не заменяют схему table.
  * choice: непустые rightAnswers и wrongAnswers; ошибочные варианты (wrongAnswers) должны отражать типичные ошибки понимания, смешение понятий или нарушение условий, а не случайный шум.
  * recall: строковый answer; дополнительный recall проверяет другой аспект того же факта и разворачивается в пару flip/input. Используй recall только для открытых вопросов на воспроизведение формулировки, формулы, доказательства или вычисление задачи, требующих развёрнутого текстового ответа.
  Если в теме есть практический пример или расчет на конкретных данных — не оставляй extraCards пустым: добавь карточку на практическое применение (перенеси входные данные в question через Markdown и спроси результат или вывод). Если тема содержит только базовое определение без прикладных примеров и нюансов, оставь extraCards пустым; запрещено плодить дублирующие перефразировки. Независимые знания оформляй отдельными фактами. Не повторяй вопросы основного и дополнительных recall или вопросы одного формата.
- В question и answer (и любых вариантах ответов) запрещено ссылаться на номера страниц, слайдов, лекций или документа: номера страниц и слайдов допустимы исключительно в служебных полях pages, source и sourceQuote.
- Каждый элемент extraCards содержит kind, question, непустой source и строковый sourceQuote. boolean содержит логический answer; choice — непустые rightAnswers и wrongAnswers; table — columns с минимум двумя категориями name и непустыми rows.
- source — подтверждённые исходником сведения для ответа с формулами и условиями. sourceQuote — дословный фрагмент предоставленного текста или читаемого оригинала PDF на страницах факта без изменения символов; если подходящей читаемой цитаты нет, верни sourceQuote="". Не выдумывай цитаты и страницы.
- Отсутствующие поля, null, неизвестные поля и старое поле cards запрещены.
- Верни issues=[] при отсутствии замечаний. Иначе перечисли конкретные неопределённости, противоречия и пропуски с номерами страниц. Верни готовый набор за один ответ.
